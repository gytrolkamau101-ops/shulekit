# ShuleKit v4 — Features pack 1–9

Run **07_features_pack.sql** after 01–06.

1. **Deputy Principal** — role + admin powers (sidebar, setup, promote)
2. **School level** — primary / secondary / combined at signup; CBC grade seed + stages
3. **Fee carry-forward** — when setting current term, optional auto arrears from previous term
4. **Promotion** — Setup → Promotion; load class; deselect; promote to target term/grade
5. **Audit** — Setup → Audit (school); Super Admin still sees global audit
6. **Parent portal** — pick Term/Year; fees (term+arrears), results, attendance for that term
7. **Timetable** — Auto-fill draft Mon–Fri rotating subjects; manual edit remains
8. **Referrals + pricing** — school referral_code; signup referral field; Super Admin pricing guidance
9. **NEMIS** — richer CSV export flag (not MoE API); use Export CSV on Students

Not included: live IntaSend checkout, WhatsApp API, full MoE NEMIS API, offline sync.
